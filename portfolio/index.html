My Journey

Hello! I'm currently pursuing my Bachelor of Computer Applications (BCA) and along the way, I've developed a deep interest in Full Stack Web Development. What started as curiosity turned into passion when I wrote my first line of HTML code. Since then, I’ve been committed to building beautiful and functional websites and applications.

To strengthen my skills, I joined a Full Stack Developer course, where I learned how to work with both front-end and back-end technologies. Throughout this journey, I’ve built several projects that reflect my learning and problem-solving skills. Each project has taught me something new — from designing responsive user interfaces to managing backend APIs and working with databases.
